# Build 158 在线编辑器验证（2026-11-03）

## 变更

- 完整编辑器和轻量编辑器统一跨平台等宽字体栈、400字重和约1.65倍行高，关闭代码连字；字号可记忆。Windows优先Cascadia Mono/Consolas，macOS回退SFMono/Menlo，中文单独回退系统字体。不依赖外网字体。
- 工具栏新增自动保存开关，按浏览器/项目记忆，默认关闭。开启一次确认后，停止输入1.5秒保存。服务停止、设备撤权清理服务端授权，重新连接按需重新确认。
- 保存绑定发起时的项目/文件/标签。保存中继续输入安排下一批，冲突/断线暂停该标签并保留内存草稿。关闭页面仍有修改时提示离开。保留原有SHA校验、写租约、构建互斥和修改前备份。

- 修复已有接口将具体文件冲突显示为“请求失败”的错误详情丢失。
- 为Monaco 0.52.2两处延迟高亮任务补充取消处理，保留标识符高亮和其他异常报告。修改记录随源码和App资源保存。

## 验证

- 核心测试：61项通过；既有证书帮助模块检查通过（工作台仍为HTTP）。
- iOS18.3.1模拟器真实HTTP服务：94项通过，包含默认关闭、未授权自动保存拒绝、开启后的实际写入、备份以及关闭后撤销授权。
- Chrome156普通HTTP上下文：89项通过，无页面脚本错误、无公网资源请求。新增覆盖字体选项、自动保存开关取消/开启、1.5秒合并、保存中继续输入、切换标签不写错文件、真实IME组词、断线草稿、手机侧真实哈希冲突、暂停重试、记忆开关和关闭后不自动写入。
- 新版页面截图完成视觉检查，开关尺寸和排版正常。完整Monaco、轻量高亮编辑器以及恢复完整编辑器均通过回归。
- 两种设备IPA完成iOS26 SDK构建及包内容校验：版本/最低系统、架构、编辑器资源、GPL和第三方许可证、发布版与开源版入口区别正确；正式包未包含模拟器回归启动入口。

## 复测

`python3 tests/RemoteCoreRun.py`；在已启动回归模拟器上执行`node tests/RemoteIntegration.mjs`和`python3 tests/RemoteHTTPBrowser.py`。浏览器脚本使用真实Network.framework HTTP接口，AI提供商部分使用确定性本地夹具。中文组词通过Chrome DevTools真实IME输入协议验证。

## 边界

测试环境为macOS上的Chrome与iOS18.3.1模拟器，尚未进行Windows/Edge或iOS15真机验收。Windows字体采用显式系统字体回退配置，未宣称完成Windows实机视觉验收。草稿保存在浏览器内存中，页面离开前提示不等同于崩溃恢复。

两种IPA版本1.0.6（158），主App及分享扩展使用iOS26 SDK、最低iOS15；ActivityKit扩展保持SDK18.2/min16.2，默认插件SDK16.4保持不变。
