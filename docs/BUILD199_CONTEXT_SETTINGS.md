# Build199：上下文保护大小设置

入口：设置 → AI 模型与连接 → 用量与账户 → 上下文保护大小。

默认 256 KiB。提供 128 / 256 / 512 / 1024 / 2048 / 4096 KiB 预设，自定义允许 64–16384 KiB 整数。本机全局保存，重启保留；每个新请求开始整理时读取一次，正在执行的请求不变。Remote / FLEX 使用同一 Dylix Runtime，因此同样生效。

这个值限制发送文本 JSON 的大小，包含工具定义，不是模型 tokens 窗口。调大可减少为预算而进行的历史折叠，但既有大工具结果和参数预览策略仍然生效。完整原文与回读、审批及模型服务商自身限制保持原逻辑。诊断记录请求当时的实际预算。

测试：82 项上下文检查、生产 Runtime 回归、5 项原生设置检查通过；通过原生自定义输入保存 768 KiB 并核对偏好文件。模拟器与设备编译、签名及 IPA 完整性检查通过。没有调用真实计费模型接口。
