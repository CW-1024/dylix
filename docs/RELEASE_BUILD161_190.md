# Dylix 1.0.7 更新日志（Build 161–190）

1. 新增“人设 / 思维”功能，支持新增、编辑、删除、单项启用，以及前置、后置、替换三种模式，提供注入预览和字节统计。

2. 新增按模型自动匹配人设及“携带 Dylix 开发提示词”开关，支持手动选择、恢复内置原文；优化配置界面，升级保留已有内容和选择。

3. 保留原有八家服务预设，新增 Kimi、xAI 和自定义 OpenAI 兼容入口，支持官方模型列表发现与手动添加。

4. 接入 Google 官方 OAuth 和 OpenRouter 官方 PKCE 授权流程，凭据存入钥匙串；模型连接支持自订 User-Agent 和按连接启用 HTTP API。

5. 新增通用 Agent 能力，包括按需加载的开发技能、只读 HTTP MCP、内置只读浏览器、项目记忆和本地长会话上下文压缩。

6. 新增分层工具管理，根据设备能力、当前输入和有效授权开放工具；保留项目修改、构建与 Git 的原有审批。

7. 打通 FLEX 与 Dylix AI，在 FLEX 菜单中进入聊天，使用完整局域网地址和授权码连接，支持选择项目、模型及新建、切换历史会话。

8. AI 可读取当前页面、视图树、控件、对象、类信息、运行时镜像和分页头文件，并获取目标窗口截图，不再只依赖手动选中的视图。

9. 接入已开放的 FLEX 原生工具页面，支持搜索、列表浏览、滚动、导航与返回。

10. 新增点击、双击、长按、滑动、拖动、双指缩放和旋转，支持可见非安全文本框输入及常见原生控件操作。

11. 支持临时修改视图显示状态、切换网络记录及撤销；滚动按实际位移判断，到达边界不再误报已移动。

12. 增加按钮父视图、控制器、所属镜像与生命周期候选信息，辅助 AI 确定 Hook 方向，明确区分方法声明与实际执行证据。

13. 优化 FLEX 聊天富文本、代码和列表显示，精简顶部工具栏，分别显示连接状态与任务状态。

14. FLEX 工具权限合并为一次会话总授权，取消原有两档权限和 30 分钟限制，支持主动撤销，新会话独立授权。

15. 收起 FLEX 聊天后保持连接、会话和任务继续运行；新增可拖动的状态悬浮球，显示读取、截图、构建、处理和回复状态，操控页面时提示“请勿触屏”。

16. 保存 FLEX 连接 IP、实际端口、授权信息、项目、准确模型和会话选择；首次配置后，在保留同一目标 App 数据及钥匙串访问权限的情况下，重启、覆盖安装或重新注入可校验恢复。

17. 修复 FLEX 切换模型后实际仍使用默认模型的问题，失效模型明确报错，不静默回落；Dylix 内置插件介绍与分享入口，可直接分享 dylib 或 deb。

18. 新增串行构建任务队列，支持排队、取消、进度与完成通知；AI 默认清理当前项目、当前会话的中间缓存后重新构建，保留源码、历史产物和日志。

19. 完善远程工具记录与手机会话同步，构建完成后及时更新会话文件列表，减少旧页面覆盖新记录的问题。

20. 修复从接收历史或分享页面导入项目时的闪退；取消打开会话时自动添加旧代码选区附件，改为手动添加。

21. 优化头文件批量导出容错，单项失败保留错误并继续处理其他可导出内容；完善补丁失败诊断，区分原文未找到、多处匹配和无实际变化。

22. 完善断线、撤权、过期对象及迟到回调处理。本次对应 Dylix 1.0.7 build190、FLEX 1.0.21，完整联动需配套更新。
