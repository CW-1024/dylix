# Build 210：FLEX 会话状态与截图发送确认

版本 1.0.9 / Build 210；FLEX 插件升级为 1.0.1，内置包按 Build 210 更新，连接诊断版本信息同步更新。

## 状态显示

展开会话与收起后的胶囊共用状态计算，不再因聊天展开而提前退出刷新。保留紧凑工具栏，仅状态文字允许两行。根据真实事件显示思考内容接收、回复、具体工具操作、工具返回、构建进度、等待授权及连接异常；页面控制保留“请勿触屏”提示。

消费模型传输状态，区分服务端只有心跳/数据但没有正文、等待模型和实际思考输出。不虚构思维内容或百分比。普通状态事件不能覆盖正在执行的工具；还有其他工具时继续显示工作中。

## 截图发送

已有 JPEG 回传、图片校验和临时视觉输入链路保留。新增调用 ID 对应的状态：captured（已获取）、sending（正在发送）、sent（NSURLSession 确认完整请求体上传）、failed/cancelled。准备请求或图片获取不表示发送成功；上传完成也不保证服务商成功处理或模型准确理解。HTTP 失败继续显示失败。

图片只发给图像能力测试通过的模型，每张 JPEG 上限仍为 120 KiB；持久化历史不保存图片 base64。状态仅携带调用 ID、请求 ID、阶段，不携带密钥或图片。失败、取消和上下文拦截清理临时状态。

Remote job 保留最新截图状态，避免 80 条事件窗口被快速输出挤出后丢失确认；插件按事件序号阻止旧状态覆盖新状态，开始新任务或切换会话时清空。

## 验证范围

UIKit 使用生产 FLEX Chat / Runtime / StatusWindow，HTTP 与无关服务为夹具，覆盖真实窗口截图和编码、会话及胶囊状态、明暗模式、配置保留与连接诊断。

真实 URLSession 与本地 HTTP 测试覆盖三种协议的完整请求体上传确认及原有协议行为；未访问外部付费模型。生产 AIRuntime 配合 ImageIO 解码真实 JPEG，覆盖临时图像输入、上传去重、失败、取消、上下文拦截、无效图片及历史不含图像数据。

未在红果真机注入联调，未声称外部模型实际读取截图，也没有 iOS 26 真机视觉验收。

## 安装

需要同时更新 Dylix Build 210 和 FLEX 插件，目标 App 重启以加载新 dylib。只升级 Dylix 不会更新已注入的插件。IPA 内置新 deb/dylib，交付目录也分别提供。配置、项目、审批、工具定义、人设及 SDK26 主程序构建方式保留。
