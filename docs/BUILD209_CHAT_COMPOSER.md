# Build 209：会话输入区与 SDK 26

版本：1.0.9 / Build 209；日期：2026-11-07。

## SDK 核对与构建默认值

Build 208 实际主程序使用 `iphoneos18.2`；包内携带 SDK26.zip 是供用户项目使用的 SDK 资源，不能证明 Dylix 自身使用 SDK26 构建。

Build 209 主程序及 Share 扩展使用真实 iPhoneOS26.0.sdk 编译和链接，并同时检查 Info.plist 与 Mach-O LC_BUILD_VERSION 的 SDK；最低部署目标保持 iOS15.0。

设备版脚本默认选用已安装的 SDK26+；旧 Xcode 则选用 `DYLIX_SDK_26_0` 或约定目录中的 SDK26，找不到时停止构建，绝不静默降级。`--sdk-root` 仍可显式指定兼容测试目标。模拟器使用本机已安装的模拟器 SDK。

LiveActivity 的 Swift framework／widget 仍由当前已安装的 Swift 编译器及 iOS18.2 SDK 独立编译，最低 iOS16.2；没有将它们伪报成 SDK26。预编译工具链和其他框架保持原样。

## 会话页面

- iOS26：仅会话页的导航项使用透明外观，去掉额外背景材质、实色和阴影。项目工作台切到编辑器时恢复该页自身的导航外观，不改全局导航栏。
- 输入区保留 UIGlassEffect，外层和 UITextView 不填实色。消息列表延伸到输入区及顶栏后方；滚动范围预留被浮动输入区遮挡的高度，使最后一条消息可滚到输入框上方。
- iOS15–18：保持原来导航外观、系统材质输入区和不重叠布局。系统“降低透明度”设置继续优先。
- 输入框取消固定 48pt 高度。按实际容器宽度排版测量，空白时保持最小高度；随文本增高到约8行或当前屏幕可用上限，再启用内部滚动。删除到短文本后恢复最小高度。
- 重新测量覆盖输入、粘贴、加载草稿、浏览器回填、发送清空、键盘展开／收起、横竖屏／窗口宽度与系统字体变化；不重写文本、不重置选区或撤销栈。

## OpenMinis 结构参考

核对上游提交 `1a71df0f381cefde80bf912b723de6f9831bc177`：

- `src/ios/Views/Chat/ChatInputBar.swift`：按当前文本宽度测量 UITextView，超过高度上限才启用内部滚动，并处理程序回填与宽度变化。
- `src/ios/Views/Chat/AIChatView/Composer/ComposerSurface.swift`：iOS26 原生玻璃表面与旧系统背景回退分开处理，避免额外矩形底板。

仅参考结构，独立以 Objective-C 实现；没有复制 Swift 代码或引入依赖。
