# Dylix 1.1.0 更新日志

汇总 Build202–210；发布构建 Build211，配套 FLEX 插件 1.0.1。

1. 优化 AI 上下文与工具调用，减少历史工具和无效思考数据占用，修复压缩标记刷屏，完善参数校验与原文回读；Token 用量支持 K／M／B 显示。
2. 新增 Exa 联网检索，本机、局域网远程和 FLEX AI 共用搜索配置。
3. 完善会话与 FLEX 状态，取消会话授权的固定 30 分钟限制，显示思考、回复及具体操作；截图区分获取、发送与失败，配套插件升级至 1.0.1。
4. 修复插件产物缺少签名导致部分环境无法加载的问题，统一补签名并校验导出与打包产物。
5. 主程序及分享扩展采用 iOS 26 SDK，优化液体玻璃会话外观；输入框随内容自动增高，低系统保留原有样式。

## 安装与验证说明

更新 FLEX 后需重启目标 App；只升级 Dylix 不会替换已注入的旧插件。截图工具仅向已通过图片能力测试的模型开放，“已发送”表示网络请求体上传完成，不保证模型理解。

App 最低支持 iOS 15。主程序及分享扩展使用 SDK26.0；独立 LiveActivity 组件仍由现有 Swift 工具链与 SDK18.2 构建，最低 iOS16.2。

已完成本地 UIKit、真实 JPEG 解码和本地 HTTP 传输测试；当前没有 iOS26 真机及目标 App 注入的整链路验收。测试边界与结果见 RELEASE_1.1.0_VERIFICATION.json。

FLEX 1.0.1 完整对应源码随 Release 的 `FLEX-1.0.1-source.zip` 提供，保留原有许可与第三方声明。
