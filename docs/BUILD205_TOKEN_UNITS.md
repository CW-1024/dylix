# Build 205：Token 用量单位

版本 1.0.9 / Build 205，2026-11-05。

统一用量统计页、按日/会话/模型/连接汇总、单次请求明细和上下文用量弹窗的 token 数字格式。使用十进制 K（1,000）、M（1,000,000）、B（1,000,000,000），最多两位小数并去除无用的末尾零。低于 1,000 显示整数，未返回的用量仍显示“未报告”，不伪装为 0。

示例：1,000 → 1K；12,345 → 12.35K；398,979 → 398.98K；1,250,000 → 1.25M；999,995 在两位小数舍入时提升至 1M，避免出现 1000K。

仅修改显示。账本、聚合计算、缓存命中率和 API 保持原始数值，不通过字符串缩写参与计算；KiB/MiB 字节大小仍保留原单位。沿用 Build 204 上下文修复和 Build 203 动态库签名修复。

验证：UsageFormattingRun.py 20 项（含零、缺失、非法值、K/M/B 阈值、舍入晋级及最大无符号整数）；UsageRun.py 28 项统计回归；ContextProjectionRun.py 121 项上下文回归，含实际/粗估 token 显示一致性。设备安装包验证 ZIP、版本和签名，并确认各自的人设资源与 FLEX manifest 未改变。
