# Dylix 1.0.5（144）附件与会话修正

## 已确认原因与修改

1. 排序使用的 updatedAt 原先在每次保存时都会更新，包括草稿、滚动与折叠状态。现仅在消息内容变化时更新，消息 ID 补齐与中断恢复产生的历史修整也保留原活动时间。置顶功能保留。
2. 系统文件入口原先使用原位打开并混入目录类型。现改为文件复制导入，支持单文件与多文件回调，选择器关闭后进入导入流程；目录继续走明确的授权入口。
3. 普通附件入口原先排除 ZIP，截图中的约48 MB ZIP 也超过文本附件20 MB限制。现支持压缩包单独导入，在本机解压为持久只读目录附件；压缩包上限128 MB，展开内容上限512 MB，密码仅本机使用。不会把整个压缩包上传给模型。
4. 项目历史会话重开时保留原 storageProjectID。存储层拒绝跨位置写入同一会话，防止静默产生另一份记录。
5. 编辑消息产生的自动备份，原标识放在长标题末尾易被截断。新旧备份在列表中均使用“[编辑前备份]”前缀。所有历史均保留，不按标题强行合并。

## 验证

- 32项会话存储检查通过：打开、草稿、附件、滚动不重排；真实消息更新排序；置顶；防跨位置重复；中断历史恢复不重排；保存与删除保护。
- 12项原有中断恢复检查通过。
- iOS18.3.1模拟器9项集成检查通过：外部分享进入已有项目会话、两次分享仅一条会话、UUID不变、保留原历史与两份附件、不重排、复用控制器、文件确认回调导入、48 MB ZIP、AI工具浏览解压目录。
- 新版两份IPA均使用iOS26.0 SDK构建、最低iOS15；插件项目内部默认仍是SDK16.4。

## 验证边界

模拟器系统文件选择器的手动测试出现文件服务空白页，因此以上文件确认测试验证的是实际代理回调到导入与保存的链路，没有把它当作iOS27真机确认按钮的验证。该按钮仍需安装新版真机复测。

重复分享产生新会话未在集成测试中复现；存储身份保护是预防修正，自动编辑备份只是已确认的一种相似列表表现，尚未断言为用户截图的唯一原因。没有删除或合并用户历史。

IPA为未签名包，需按原有方式签名后安装。发布版保留反馈、Telegram、许可证及开源地址；开源版保留许可证及开源地址。
