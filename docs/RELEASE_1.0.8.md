# Dylix 1.0.8 更新日志

内部构建：191；配套 FLEX 插件：1.0.0。整理日期：2026-11-05。

本次正式版本汇总 Build161–190 的改进，Build191 同步主 App、分享扩展、实时活动组件和插件版本标识。FLEX 版本由 1.0.21 调整为 1.0.0，保留当前功能与配置存储格式。

1. 新增人设与思维配置，支持模型自动匹配、前置／后置／替换、注入预览与原文恢复，可选择是否携带 Dylix 开发提示词。
2. 扩展模型服务，新增 Kimi、xAI、自定义兼容入口及官方授权流程，支持模型发现、能力测试、自订 User-Agent 和 HTTP API，修复模型切换不生效。
3. 新增通用 Agent，接入按需技能、只读 MCP、内置浏览器、项目记忆及长会话上下文压缩，完善分层工具权限。
4. 打通 FLEX 与 AI，支持截图、控件与类信息、头文件、工具页面导航、手势输入及临时视图修改与撤销；完善聊天、会话总授权和状态悬浮球，保存连接、项目、模型及会话选择。
5. 优化构建任务队列，支持排队、取消、进度和完成通知；AI 默认清理当前项目、当前会话缓存后重编译，保留源码、历史产物与日志。
6. 完善远程与手机会话同步，工具记录和构建产物及时刷新，保护草稿及较新的远程记录。
7. 改善补丁失败诊断，区分原文未找到、多处匹配和无实际变化，提供定位与重读信息。
8. 修复项目导入闪退、旧代码选区自动变附件、滚动边界误报等问题，增强头文件导出容错、断线及过期状态处理。

安装：完整联动请配套更新 Dylix 1.0.8（191）和 FLEX 1.0.0。IPA 需按原有方式签名；独立 dylib 与 deb 按自己的安装方式选择。

公开版目录仅分发四项有 MIT 许可的预设数据；仅限私用的无许可正文不打包。已有本地配置与人设功能保留。
