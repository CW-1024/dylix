# Build 159 在线编辑工作区验证（2026-11-03）

## 实现

工具栏撤销/重做与当前文件关联，空历史置灰。完整编辑器使用Monaco编辑栈；轻量编辑器新增差量历史、文字输入合并、中文组词合并和选择位置恢复。保存与自动保存不清空当前文件的编辑历史，撤销后的内容沿用原有保存策略。关闭文件/页面或切换项目结束当前编辑历史，持久恢复仍由备份与Diff提供。

## 布局与默认值

自动保存初始偏好开启，手动关闭按浏览器/项目记忆；首次设备/项目写入授权仍需一次确认。导航收起为图标栏，项目文件栏可拖动、键盘调整、双击复位或收起。全屏保留文件与历史，Esc或退出按钮恢复；Ctrl/Command+Alt+Enter切换。工具栏分组、跨平台等宽字体和本地语法高亮沿用现有设计。手机文件栏浮层展开。

- `python3 tests/RemoteHTTPBrowser.py`：113项真实浏览器检查通过；Chrome156 + iOS18.3.1模拟器原生HTTP服务，无页面脚本错误，无公网资源请求。AI部分为确定性本地提供商夹具，非公网模型效果测试。
- 新增布局检查：默认自动保存首次授权与记忆关闭、导航折叠与图标栏、收起文件栏后代码区扩宽、真实鼠标拖动分隔线、键盘调整与最小宽度、全屏按钮和快捷键、Esc恢复、全屏保留内容、窄屏文件浮层、390px宽屏无水平溢出、状态栏在可视范围内。
