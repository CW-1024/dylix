# Remote 与服务商、Persona、Agent 的衔接

版本 1.0.7（165）。Remote继续在iPhone/iPad上通过同一AIRuntime执行；网页没有另一套模型密钥或工具执行器。

## 已接通

- 原`ai_connections`返回手机保存的可用模型，包含新增的Kimi、xAI与自订兼容连接；选择连接和模型仍针对下一次发送，按项目默认规则保留。
- 增加白名单元数据：服务商名称、线路协议、实测能力；未测状态保持`unknown`。API密钥、token、Base URL和User-Agent配置不返回。
- AI页面新增可展开配置面板：服务商与模型、各项实测能力、当前生效人设名称/模式、技能数量、五项Agent总开关及当前项目进行中的构建队列任务。页面进入或刷新时取得快照；发送时由手机重新读取实时设置。
- Persona沿用同一引擎，包括总开关、唯一生效项、前置/后置/替换及防重复注入。网页只显示状态元数据，不输出人设正文。
- 技能按需读取、项目记忆、JS只读浏览、构建队列沿用手机运行时和独立模块开关。MCP工具仅在**对应会话**已经授权时生效，不继承其他会话授权。
- 项目文件、构建和Git继续经过现有Remote权限及审批流程；设置中的UA与HTTP授权由手机请求端直接采用。

## 隔离档边界

Remote runtime 显式标记`remoteExecution`。C档只读元数据/自家插件日志在网页AI中不下发schema，执行前的再次校验也拒绝。原因是现有Remote审批发生在浏览器，不能当作C档要求的手机原生逐次确认。A/B档原流程保留。未添加C档写入、扫描、复制App或注入能力。

## 仍由手机管理

连接/API密钥/OAuth、User-Agent与HTTP授权、人设编辑、Agent总开关、MCP服务器与按会话授权、C档精确目标登记和审计仍在手机管理。本次没有把全局敏感配置暴露成浏览器写接口，也没有把WebDAV权限扩大到模型密钥、Agent存储或外部系统目录。

以后如增加网页管理入口，应按现有设备撤权、会话归属、版本冲突检查及审批流程逐项接入。配对成功不代表取得所有手机功能权限。
