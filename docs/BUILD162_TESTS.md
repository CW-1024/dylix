## 模拟器交互

设备：iPhone16 Pro Max，runtime显示iOS18.3，实际18.3.1（22D8075）。

1. 五份内置项显示名称、描述、前置徽标、正文UTF-8字节数及独立开关。
2. 将同一内置项从前置保存为后置，再保存为替换；列表总数仍为五，正文仍521字节。
3. 开启替换项，再开启另一份：前者自动关闭，状态栏跟随当前选择。
4. 对编辑过的内置项执行恢复原文，模式恢复前置；取消当前选择并关闭总开关。
5. 安装最新模拟器包并重启后，五份条目、前置模式、总开关关闭状态恢复；无障碍「编辑」入口可以正常进入编辑页。
6. 深色下核对列表、模式编辑与选项页，描述、前缀、自检口令及回执均能显示；返回后取消编辑，实际配置保留。
7. 另起进程持久化、三种模式的实际请求字节与预览一致由上述核心/运行时测试覆盖。
