# Dylix 1.0.9 更新日志

汇总 Build193–199，并纳入 Build201 上下文优化；当前构建 Build201。配套 FLEX 插件保持 1.0.0。

1. 优化 AI 上下文管理，主动精简历史工具记录与长回复，修复调大保护上限后仍携带大量旧内容的问题；保留近期结果和原文回读，支持分类统计及自定义保护大小。
2. 新增 AI 用量与余额统计，支持按时间、会话、模型和连接查看输入、输出、思考及缓存用量；自动识别支持的余额接口，完善硅基流动兼容与查询诊断。
3. 完善 FLEX 跨设备连接，细化网络、超时、系统策略与配对错误，支持复制诊断；修复超时失效、响应不完整及异常数据处理问题。
4. 完善隐根打包的 Substrate 链接、最终 dylib 签名及产物检查，提高打包兼容性。

说明：用量以服务商实际返回为准；余额仅支持已适配接口。上下文保护大小是本机文本预算，不是模型窗口。隐根真机安装与加载仍需实机验证。
