# Dylix 1.0.7 · Build 160

汇总 Build 148–159 的最终功能；Build 160 同步 App、分享扩展和灵动岛组件版本号。

1. 新增 Dylix Remote 局域网工作台，电脑浏览器可连接手机，支持随机或固定授权码、设备授权管理。
2. 接通远程项目管理、在线构建、Git、AI、二进制分析和 WebDAV，任务仍在手机本机执行。
3. 升级文件管理，支持目录浏览、搜索排序、列表与网格、预览、多文件上传下载及项目 ZIP 导出，移除传输文件的固定大小上限。
4. 集成离线 Monaco 编辑器，支持多语言语法高亮、多标签、查找替换、字号调整、换行和备份 Diff。
5. 新增默认开启的自动保存、撤销与重做，保留修改前备份和文件冲突校验，记住手动关闭的选择。
6. 编辑工作区支持导航折叠、文件栏拖动缩放与收起、全屏编辑，重新整理工具栏和代码字体。
7. 完善远程 AI 会话，支持模型与思考档位选择、流式 Markdown、代码块、工具过程、停止生成和稳定阅读。
8. 局域网服务与 AI 回复期间保持前台屏幕常亮，优化共享音频辅助和后台恢复；改善手机源码粘贴后的阅读位置与系统编辑菜单语言。

## 安装与说明

- 本次 GitHub 附件为**开源版未签名 IPA**，安装前请按自己的设备与签名方式处理签名。开源版提供项目开源地址及 GPL 许可证入口。
- 主 App 与分享扩展使用 **iOS 26 SDK** 构建，最低 iOS 15；ActivityKit 组件使用 SDK 18.2、最低 iOS 16.2。
- App 内插件构建默认仍为 **SDK 16.4 / 最低 iOS 15**，可按项目切换。
- Remote 在手机「设置 → 远程开发 → 局域网远程」开启；工作台资源随 App 离线打包。HTTP 为局域网明文传输。
- 自动保存首次使用需确认当前设备/项目的写入授权。后台仍受 iOS 调度、锁屏文件保护及系统中断影响。
